# Contributing

Contributions that keep Tab Saver small, local-first, and understandable are welcome.

1. Fork the repository and create a focused branch.
2. Use Node.js 20 or newer.
3. Run `npm run check` and `npm test` before submitting changes.
4. Load the repository as an unpacked extension in a Chromium-based browser and manually exercise affected UI flows.
5. Keep permissions minimal. New browser permissions require a clear justification.
6. Add tests for changes to session parsing, validation, import/export, or URL handling.
7. Never commit real browsing exports, credentials, private URLs, or generated extension packages.

Please keep pull requests focused and explain user-visible behavior and security/privacy implications.
